# Sky Art font data

- Noto Sans CJK SC Bold: Noto CJK project, https://github.com/notofonts/noto-cjk, SIL Open Font License 1.1 (OFL.txt). Full font bundled to support arbitrary covered Simplified/Traditional Chinese and Latin characters without remote runtime font requests.
- Chinese single-line polylines: LingDong-/chinese-hershey-font, https://github.com/LingDong-/chinese-hershey-font, MIT (chinese-single-LICENSE.txt). STRK-Heiti data derives from Source Han Sans, which is licensed under SIL OFL; see OFL.txt for the upstream font conditions.
- Hershey futural/scriptc JSON: https://github.com/techninja/hersheytextjs. JSON data is public domain; extractor code is not bundled. Attribution retained in hershey-LICENSE.txt.

The outline font is the default. Single-line and script are optional styles, not replacements for contour lettering.
